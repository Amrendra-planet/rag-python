# RB-003 — payments-api high CPU
Service: payments-api
Failure mode: sustained high CPU

Symptoms:
- payments-api CPU is consistently high.
- Payment request latency increases.

First checks:
1. Check CPU by instance.
2. Review recent payments-api deployments.
3. Inspect payment-processing latency and request volume.
4. Check logs for repeated processing or retry activity.

Do not apply checkout-api-specific remediation to payments-api without verification.
