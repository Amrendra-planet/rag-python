# RB-002 — checkout-api too many connections
Service: checkout-api
Failure mode: database connection exhaustion

Symptoms:
- Errors contain "too many connections".
- Requests may fail while the database connection pool is exhausted.

Likely cause:
The checkout-api connection pool is exhausted, commonly because connections are held too long or traffic has increased beyond the configured pool capacity.

First checks:
1. Check active database connections.
2. Check checkout-api connection-pool utilization.
3. Look for long-running queries and connection leaks.
4. Compare current traffic with recent baseline.

Mitigation:
Reduce the source of connection pressure, investigate long-running queries, and only increase pool/database limits after confirming capacity.
