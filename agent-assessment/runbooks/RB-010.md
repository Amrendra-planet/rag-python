# RB-010 — inventory-api out-of-stock mismatch
Service: inventory-api
Failure mode: stock consistency issue

Symptoms:
- Product availability shown to customers does not match inventory records.

Checks:
1. Compare cached inventory with source-of-truth records.
2. Check recent inventory synchronization jobs.
3. Inspect failed synchronization events.
4. Escalate discrepancies affecting multiple warehouses.
