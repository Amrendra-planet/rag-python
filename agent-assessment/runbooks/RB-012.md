# RB-012 — checkout-api incident 2026-08-10
Service: checkout-api
Incident date: 2026-08-10
Failure mode: connection exhaustion following a deployment

Incident:
On 2026-08-10, checkout-api experienced elevated failures after a deployment changed connection handling. Connections were retained longer than expected, exhausting the database connection pool.

Root cause:
A connection-management regression in the deployed checkout-api version caused connections to remain occupied longer than expected.

Fix:
The team rolled back the affected checkout-api version and then corrected the connection-management behavior before a later redeployment.

Validation:
Database connections returned to normal and checkout request failures subsided after rollback.
